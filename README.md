Aplicativo de Tarefas

Aplicativo desenvolvido em Android Studio para gerenciamento de tarefas do dia a dia, com interface intuitiva e design personalizado.

Dupla de Desenvolvedores

Matheus de Freitas Finotti

Murillo Rangel

Sobre o Projeto

O projeto consiste em um aplicativo mobile voltado para a organização pessoal. Conta com uma identidade visual própria (incluindo ícone customizado com tema em tons de verde escuro e lápis branco) e foi estruturado utilizando as melhores práticas de desenvolvimento Android moderno.

🛠️️ Tecnologias Utilizadas

Linguagem: Kotlin

Ambiente de Desenvolvimento: Android Studio

Controle de Versão: Git & GitHub

📱 Funcionalidades

Tela inicial com ícone personalizado (ic_launcher).

Estrutura base pronta para expansão de rotinas e listas de afazeres.

Compatibilidade com versões recentes do sistema operacional Android.

⚙️ Como Executar o Projeto

Clone este repositório no seu computador:

git clone https://github.com/matheusfreitasfinotti-code/Tarefas.git


Abra o Android Studio.

Vá em File > Open e selecione a pasta do projeto clonado.

Aguarde a sincronização do Gradle.

Conecte um emulador ou dispositivo físico e clique no botão Run (▶) para compilar e executar o aplicativo.
